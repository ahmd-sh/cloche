CLOCHE
GitHub

App builds on your phone, from your computer, over Tailscale.

macOS and Linux

curl -fsSL https://ahmd.sh/cloche/install.sh | sh

Install

Install Cloche using the command above. You need Tailscale on the computer and the phone, signed in to the same account.

With Go

go install github.com/ahmd-sh/cloche/cmd/cloche@latest && cloche setup

Pair

Android

cloche pair -android

iOS

cloche pair -ios

Friend's phone on their own Tailscale

cloche pair -android -friend sam

Use

Setup installs a skill for your agent (Claude Code, Codex, OpenCode, Pi). You may need to tell it to use Cloche to ship you builds.

cloche push app-debug.apk -m "Rename inline"
cloche push ──▶ cloche serve ◀── tailnet ── Cloche on the phone
  (agent)        (computer)                notifies; a tap installs

Cloche on your phone will check every build against your computer's key. README for more info.
