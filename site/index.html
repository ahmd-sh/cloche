CLOCHE
GitHub

App builds on your phone, from your computer, over Tailscale.

An agent on your computer pushes a build. Your phone gets a notification, checks the build, and a tap installs it. iPhones get builds through a web app.

Install

You need Tailscale on the computer and the phone, signed in to the same account.

macOS and Linux

curl -fsSL https://ahmd-sh.github.io/cloche/install.sh | sh

The script downloads cloche from the latest release, checks it against the release's checksums, puts it in your user folder, and runs cloche setup. Setup keeps cloche serve running in the background and adds a skill that tells Claude Code how to use cloche.

With Go

go install github.com/ahmd-sh/cloche/cmd/cloche@latest && cloche setup

Pair

cloche pair

Scan the code with your Android phone's camera. The page it opens helps you install Tailscale and Cloche, then pairs them.

cloche pair -ios

For an iPhone. Builds for it need to be signed for that iPhone.

Use

cloche push app-debug.apk -m "Rename inline"
cloche push ──▶ cloche serve ◀── tailnet ── Cloche on the phone
  (agent)        (computer)                notifies; a tap installs

Nothing installs without a tap. The phone checks every build against the computer's key, and refuses one signed by a different key from the installed app. The README covers the rest.
